# FORTRESS Security Analysis

## Identified Security Risks

1. Excessive IAM permissions
2. Unauthorized infrastructure modifications
3. Disabled audit logging
4. Undetected suspicious activity
5. Exposure of sensitive information

## Proposed Mitigations

| Risk | Mitigation |
|---|---|
| Excessive permissions | IAM Least Privilege |
| Unauthorized changes | SCP restrictions |
| Missing audit logs | CloudTrail |
| Suspicious activity | GuardDuty |
| Data exposure | AWS KMS |

## Conclusion

FORTRESS demonstrates a layered approach to AWS cloud security by combining identity management, preventive controls, monitoring, and encryption.
