
# Amazon GuardDuty Configuration

## Purpose
Detect suspicious activity and potential threats in AWS accounts.

## Detection Capabilities
- Unusual API activity
- Potential compromised credentials
- Suspicious network connections
- Malware-related activity

## FORTRESS Implementation
- Enable GuardDuty in supported regions.
- Configure centralized security administration.
- Review security findings.
- Establish alerts for high-severity findings.

## Expected Outcome
Improved threat visibility and faster security incident response.
