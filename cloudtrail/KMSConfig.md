
# AWS KMS Encryption Configuration

## Purpose
Protect sensitive information using encryption keys.

## Security Controls
- Customer managed KMS keys.
- Key rotation where supported.
- Restrict key administration permissions.
- Control key usage through IAM and key policies.
- Monitor key activity through CloudTrail.

## FORTRESS Implementation
Use AWS KMS to protect centralized audit logs and sensitive workload data.

## Expected Outcome
Improved data confidentiality and encryption governance.
